# حالة الحماية — 16 أكتوبر 2026

خدمات المواطنين تظل متاحة بدون حساب. بيانات الإدارة والتعديل والحذف والتكويد تخضع لصلاحيات موظف نشط وجلسة Auth فعلية. تغيير الدور في المتصفح لا يمنح صلاحية في قاعدة البيانات.

- الزائر لا يقرأ جداول الإدارة ولا يعدل السجلات الموجودة. يسمح له بإنشاء طلب/شكوى بحالة pending؛ السيرفر يفرض القيم الحساسة.
- الاستعلام العام محدود بمطابقة الاسم والرقم القومي والهاتف. أربع دوال مواطن فقط مستثناة من حاجز REST، ولا تعيد الصور أو بيانات الموظفين.
- الصور في bucket خاص. المواطن يرفع صورًا بالأنواع والمسار المسموحين فقط، ولا يستطيع قراءتها أو حذفها. الموظفون النشطون يقرؤونها بروابط موقعة.
- أُغلقت دوال الصيانة القديمة عن العملاء. get_staff_list يستخدم RLS وصلاحيات المستدعي. دالة الدور تتحقق من جلسة قائمة ومن نشاط الموظف، فتمنع الحساب المعطل والجلسة المحذوفة.
- Cloudflare Turnstile يحمي دخول الموظفين على السيرفر، حتى لو استُخدمت API مباشرة. لم يعد التحقق قائمًا على مسألة حسابية في المتصفح.
- كلمات مرور الموظفين الجدد تتطلب 12 خانة وحروفًا كبيرة وصغيرة وأرقامًا؛ لا تغيير لكلمات المرور الحالية. جلسة الوصول 15 دقيقة مع تدوير رموز التجديد. تغيير كلمة المرور يحتاج الحالية.
- استمرت حماية XSS وCSP دون inline scripts أو eval، مع HSTS ورفض الإطارات وnosniff. بقي WAF وTLS strict.
- التكويد ذري، مع حجز يمنع تكرار الأكواد الجديدة. التعارض التاريخي 1960 محفوظ على سجلين.
- مكتبات التطبيق محلية ومثبتة: SheetJS 0.20.3 وSupabase JS 2.107.0. البناء ينشر قائمة أصول فقط، ويستبعد الأسرار والمراجعة والاختبارات.

التحقق الحالي: 29 اختبار متصفح محلي ناجح، و19 اختبار SQL حي ناجح داخل معاملات ملغاة. الدخول المباشر بدون CAPTCHA رُفض بخطأ captcha_failed؛ قراءة جدول orders بدون دخول HTTP 401، والاستعلام العام المقيد HTTP 200. لا توجد ثغرات npm معروفة وقت الفحص.
